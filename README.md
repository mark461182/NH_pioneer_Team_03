# 풀옵션 · NH선물 REST API Pioneer 1기

국내와 해외, 선물과 옵션까지 — 빠짐없이 다뤄 보자는 뜻입니다.

모의환경에서 실행한 기록으로 결과를 분석합니다.

**활동 기간:** 2026.10.21 ~ 2026.12.11
**과제 제출:** 매주 금요일 23:59 까지 (마감 전 마지막 커밋이 제출본)

## 저장소 구조

**주차 폴더 하나 = README.md(보고서) + 코드 파일 + `results/`·`screenshots/`** 입니다.

```
weekNN/
  README.md       그 주차의 보고서 — 과제·실행 방법·전략·사용 API·결과·분석·오류·개선
  (코드 파일)      프로그램 코드와 설정 파일
  results/        실행 근거 원본 데이터 (JSON·CSV·로그 등)
  screenshots/    실제 화면 캡처 (README 본문에 이미지로 넣음)
```

주차마다 Markdown 문서는 README.md 하나만 둡니다.

## 인증 정보 관리

APP Key 와 Secret Key 는 **이 저장소에 두지 않습니다.**
사용자 홈 폴더의 설정 파일에만 보관하며, 저장소에는 빈 서식(`config.example.yaml`)만 둡니다.

| 운영체제 | 설정 파일 경로 |
| --- | --- |
| Windows | `%USERPROFILE%\NHFutures\config\config.yaml` |
| macOS / Linux | `~/NHFutures/config/config.yaml` |

APP Key 와 Secret Key 는 모의·실전 환경별로, 국내·해외 시장별로 각각 발급됩니다.

## 기록 시 주의사항

- **인증정보를 올리지 않습니다.** APP Key, Secret Key, 토큰, 계좌번호·비밀번호와 개인 설정 파일은 저장소에 넣지 않습니다. 화면과 로그의 계좌 식별정보·개인정보는 가립니다.
- **실행 환경을 구분합니다.** 시뮬레이션, 모의계좌 주문, 실전 기록을 섞지 않고 어느 것인지 적습니다.
- **꾸미지 않습니다.** 주문 접수와 실제 체결을 구분하고, 실행하지 않은 수치를 만들지 않습니다. 손실 결과도 그대로 적고 분석합니다.
